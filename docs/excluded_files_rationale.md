# Excluded Files and Rationale

- Original thesis PDFs/DOCX and planning documents: excluded because they are not needed for repository execution and may include non-public context.
- Original operator Excel workbooks and OpenDSS source files: excluded to protect confidentiality.
- Notebooks and exploratory scripts: excluded to keep the public repository focused and reproducible.
- Seed-level JSON/log files from optimization runs: excluded because consolidated CSV results are provided.
- Python caches, checkpoint folders, temporary files, and generated intermediate DSS files: excluded as non-source artifacts.
- Local absolute paths: removed or replaced with public relative paths/sanitized placeholders.

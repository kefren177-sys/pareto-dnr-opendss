# Confidentiality Note

The real-system case is released only in anonymized form. The repository excludes:

- original operator spreadsheets and documents;
- commercial or geographic identifiers;
- internal feeder/circuit names;
- geolocation data and maps;
- original thesis PDFs and working documents;
- local absolute paths.

The public files retain only anonymized buses/branches, structured Annex C data, anonymized topology exports, consolidated metrics, representative configurations, and Pareto results needed to verify the article. The full evaluated-solution cloud for the real-system case is excluded because it is not necessary to support the manuscript claims and may disclose more network-level detail than required.

The public package includes the anonymized AutoCAD-derived topology and `real_system_annex_C_data.xlsx`. These files use only neutral labels such as `S/E 10`, `S/E 20`, `S/E 30`, feeders `11` to `34`, line sections `S-1` to `S-131`, and reconfigurable links `S-110` to `S-131`.

This supports scientific traceability while reducing disclosure risk for the operator system. The repository does not claim that the original operator data are public.

# Confidentiality Note

The real-system case is released only in anonymized form. The repository excludes:

- original operator spreadsheets and documents;
- commercial or geographic identifiers;
- internal feeder/circuit names;
- geolocation data and maps;
- original thesis PDFs and working documents;
- local absolute paths.

The public files retain only numbered buses/branches, anonymized OpenDSS data, consolidated metrics, representative configurations, and Pareto results needed to verify the article. The full evaluated-solution cloud for the real-system case is excluded because it is not necessary to support the manuscript claims. This supports scientific traceability while reducing disclosure risk for the operator system.

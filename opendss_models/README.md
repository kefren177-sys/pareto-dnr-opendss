# OpenDSS Models

Each subdirectory contains the OpenDSS model associated with a study case.

OpenDSS is used as an AC electrical evaluator. It does not perform optimization. Candidate configurations are represented by opening line/switch elements before solving the power flow.

The `generated/` directory contains DSS files generated by the Python code for public cases. The real-system OpenDSS model is anonymized and contains numbered buses and branches only.

The public real-system model is provided for traceability of the anonymized electrical representation. A complete public rerun of the real-system optimization is not claimed because the restricted operator reliability workbook is not released.
